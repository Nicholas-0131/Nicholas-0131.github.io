\section*{研究関心分野}

微分幾何学、幾何解析学、凸幾何学、および
カケヤ問題とその関連問題。
特に、凸カケヤ集合とその変種、極値的な幾何配置、
ならびに凸性や幾何学的制約のもとでの
面積・直径・周長の相互関係に関心を持つ。

\section*{研究活動}

\entry
{凸カケヤ集合に関する研究}
{2026年9月～現在}
{指導教員：王作勤教授（中国科学技術大学）}

\begin{itemize}
  \item
  あらゆる方向の長さ1の線分を含む凸集合について、
  面積・直径・周長の間の定量的関係を研究している。

  \item
  極値的な幾何配置、幾何不等式、
  および凸体の極限挙動を考察している。

  \item
  支持超平面、支持関数、凸包など、
  凸幾何学の関連手法を研究している。
\end{itemize}

\section*{数学論文・執筆活動}

\textbf{双曲平面のいくつかの幾何学的性質}
\hfill{\small 2026年}\\
\emph{
個人研究論文。
中国科学技術大学数学科学学院の
学生刊行物『蛙鳴』第68号に掲載。
}

\begin{itemize}
  \item
  双曲幾何学のポアンカレ上半平面モデルについて、
  ヒルベルトの公理体系との整合性や
  その変換群などの性質を考察した。

  \item
  双曲三角形の正弦定理・余弦定理、
  およびデザルグの定理、
  パップスの定理などを研究した。
\end{itemize}
